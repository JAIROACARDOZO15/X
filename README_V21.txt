PLATAFORMA ACADEMICA UAN — V21

CAMBIOS FINALES

1. COORDINADOR — NOTAS Y CORRECCIONES
- Ahora se muestra el catalogo completo del plan de estudios, no solamente materias con grupos.
- Las materias sin grupos aparecen como "NO PROGRAMADA".
- Se muestran contadores de materias del plan, materias con grupos y materias por programar.
- Se agrego selector para saltar directamente a cualquier materia.
- En el detalle de un grupo ahora hay "← Todas las materias" y "Inicio" para regresar sin quedar atrapado.
- Se conserva la edicion administrativa de notas, el marcado de correcciones y la fecha limite docente de V20.

2. ESTUDIANTE — MATRICULAR MATERIAS
- Se reemplazo la tabla extensa por tarjetas de seleccion.
- Contador de creditos disponible permanece en vivo.
- Materias atrasadas, bloqueadas, electivas y materias del nivel actual tienen estados visuales distintos.
- La solicitud definitiva conserva la misma logica de validacion y solo puede enviarse una vez.
- Cuando la matricula ya fue procesada, el horario se presenta como tarjetas por materia/grupo.
- Cuando la solicitud esta pendiente, se presenta como un resumen visual de las materias seleccionadas.

3. ESTUDIANTE — AVANCE DEL PLAN DE ESTUDIOS
- Nuevo panel con porcentaje de avance total.
- Resumen de creditos aprobados/restantes y materias aprobadas/pendientes.
- Barra de progreso general.
- Cada nivel del pensum tiene su propio progreso.
- Cada materia muestra estado y nota.
- Se mantienen los datos del historial academico existente.

4. CACHE
- index.html usa estilos.css?v=21 y app.js?v=21 para evitar que GitHub Pages conserve la version anterior.
